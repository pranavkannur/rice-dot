# rice_dot — Context & System Architecture

## 1. Overview & Vision
`rice_dot` is a centralized, reproducible, and modular dotfiles repository designed to configure, theme, and manage an Arch Linux desktop environment ("rice") inspired by the **Caelestia-dots** aesthetic.

The goal of this repository is to provide:
- **Reproducibility:** A clean mechanism to restore and replicate system styling and application configurations onto a fresh machine.
- **Modularity:** Separation of individual application configs (compositor, terminal, bar, shell, editors) so components can be updated or swapped independently.
- **Cohesive Aesthetics:** A unified, dynamic Material You color palette (via `matugen`) with Dark/Light mode, applied across the compositor, bar, terminal, editor, Spotify, Discord, and VS Code.
- **Developer-First Experience:** Integrated developer tools (lazygit, clipboard manager, color picker, project launcher, scratchpad terminal) accessible via keyboard shortcuts.
- **Interactive Customization:** A visual Settings Menu for wallpaper selection, opacity/blur/animation tuning, VPN/DNS controls, and theme toggling — without manual config editing.
- **Maintainability:** Safe symlink-based deployment via an idempotent installer that backs up existing configuration files before applying new ones.

## 5. Deployment & Configuration Principles
1. **Non-Destructive Symlinking:**
   Before symlinking any dotfile, the installer must detect existing files in `~/.config` or `~` and create a timestamped backup in `~/.config_backup_<timestamp>/`.
2. **Package Tracking:**
   Keep package dependencies clearly documented in plain text manifests (`pacman-packages.txt` and `aur-packages.txt`) to allow automated provisioning.
3. **Hardware Independence:**
   Isolate machine-specific configuration (such as specific monitor resolutions, refresh rates, and GPU settings) into optional override files (e.g., `monitors.conf`).
4. **Dynamic Theming:**
   All color values in configs use `matugen`-generated template tokens rather than hard-coded hex values, enabling instant palette changes when the wallpaper or dark/light mode is switched.
5. **Clean Git Tracking:**
   Keep transient files, caches, and secrets out of version control via `.gitignore`.
